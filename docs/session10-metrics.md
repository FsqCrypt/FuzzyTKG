### 2.2 3in 深度分析 — 主力收益查询

```
         Baseline  →  Module 1     Δ
MRR:     0.1415   →  0.1602      +12.8%
HITS@1:  0.0749   →  0.0825      +10.2%
HITS@3:  0.1515   →  0.1755      +15.9%   ← 提升最大
HITS@10: 0.2697   →  0.3093      +14.7%
```

**H@3 提升最大（+15.9%）是关键洞察**：方法的主要效果是把正确答案从排名 4-10 推进了 Top-3。这不是简单的全局平移——是精准修复了之前被 B-spline 过度惩罚的"中等分数正确答案"。H@1 也提升 10.2%，说明部分实体被直接推到了第一名。

### 2.3 2in 分析 — 结构性限制

```
MRR:     +0.4%    ← 几乎持平
HITS@1:  -1.5%    ← 微降
HITS@10: +2.0%    ← 微升
```

**H@10 升但 H@1 降。** 这与理论分析完全一致：2in 只有一个正分支，negation 是核心区分信号。减弱 penalty 帮助了边界实体（排名 5→10）但让部分假阳性漏网，伤害了 Top-1 精度。要修复 H@1 的下降，需要 Per-Cluster B-spline（让 penalty 更准，而非更轻）或 alpha-adaptation（让算子本身 relation-aware）。

### 2.4 非否定查询

- **终端 intersection/union（2i/3i/2u）**：四指标全部 ~0%。Session 9 数学证明的实证——线性校准保持排序
- **链式查询（ip/up）**：四指标均有正向提升。up H@1 +4.2% 最高——投影非线性放大校准效应

## 三、实验规范：后续所有实验必须报告四指标

### 3.1 规则

后续所有实验（Session 11+）记录结果时必须同时报告 **MRR、HITS@1、HITS@3、HITS@10** 四项指标，不再仅报告 MRR。

### 3.2 理由

1. **多指标验证有效性**：单一 MRR 可能掩盖方法在不同排名区间的差异化效果（如 2in 的 H@1↓ H@10↑ 揭示的结构性限制）
2. **论文要求**：原论文 Table IV 报告 MRR，Table XII 报告 HITS@1。Reviewer 会期待同时看到两者
3. **诊断价值**：MRR 不变但 H@1↑H@10↓ vs MRR 不变但 H@1↓H@10↑——含义完全不同：前者改善顶部精度，后者改善召回
4. **数据已存在**：评估代码（`models.py:686-696`）已计算全部四指标，只是从未被提取，零额外成本

### 3.3 提取命令模板

每次实验后从日志提取四指标：

```bash
grep "Test <query_type> " test.log | grep -E "MRR|HITS[0-9]"
```
